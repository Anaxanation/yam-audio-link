# Audio Link для Alice Homebrew

Экспериментальный плагин для Станции Мини 1. Передаёт стереозвук PCM 48 кГц по UDP между двумя устройствами в домашней сети. Для этой версии достаточно штатных `aplay` и `arecord`. Пакеты YAM 0.1.0 используют другой сетевой формат и требуют FFmpeg.

## Установка на Мини 1

В Alice Homebrew откройте «Настройки → Добавить источник» и вставьте `https://github.com/Anaxanation/yam-audio-link`. Проверьте и подтвердите сторонний источник. В магазине установите «Audio Link», внесите IPv4 второй колонки в конфигурацию и включите плагин. Для нативного SDK 2 Homebrew запрашивает право `system.full-access`.

Для Лайт 1 скачайте `.aliceplugin` из `docs/packages`, откройте его как ZIP и извлеките `plugin.elf`. Скопируйте файл через SSH или ADB в `/tmp/audio-link-linux-arm64`. Пример, если Мини находится по адресу `192.168.1.31`:

```sh
chmod +x /tmp/audio-link-linux-arm64
/tmp/audio-link-linux-arm64 recv 192.168.1.31
```

На Мини выберите «Тестовый сигнал», чтобы на Лайт прозвучали короткие сигналы. В режиме «Приём» укажите IP отправителя. Для проверки обратного направления выберите приём на Мини и запустите `test IP_МИНИ` на Лайт. Порт по умолчанию `47668/udp`. Приёмник фильтрует отправителя по IPv4. Поток около 1,6 Мбит/с, без шифрования. Используйте в домашней сети.

В Homebrew тест отправляет три секунды PCM один раз при включении и пишет результат отправки в журнал. После этого процесс ждёт отключения. Чтобы повторить тест, выключите и снова включите плагин. Команда `test` в терминале завершает работу сразу после отправки.

После перезагрузки Лайт содержимое `/tmp` сбрасывается.

### Звук штатной Алисы

Выбирайте «Передача выхода ALSA» только если вывод динамика уже продублирован в проверенный ALSA Loopback PCM. Типовой адрес `plughw:CARD=Loopback,DEV=1`. Плагин не настраивает захват штатного динамика сам. На Лайт 1 штатная карта Loopback не обнаружена. Зеркалирование штатной Алисы на Мини 1 пока не подтверждено, возможна задержка между колонками.

## Сборка

```sh
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags='-s -w' -o audio-link-linux-arm64 main.go
```
